## 当前事实摘要

- 系统源码在 `backend/` 与 `frontend/`；课程文档、过程留痕、验收证据和提交清单在 `docs/`。
- 当前证据记录了核心功能、前后端回归和课程“360 活跃会话”口径的测试结果。该口径与“360 个请求持续在途”不同，报告中分别说明各自条件和结论。
- 持续高在途正式负载下的 280 ms P95 尚未通过。最近一次云端短测使用未提交候选代码，包含连接重置和数据库连接耗尽的无效轮次；测试总结记录了数值、问题和后续阶梯验证顺序。云端测试已暂停，启动新一轮前需先检查服务器状态并按总结中的步骤恢复。
- 个人研究分析报告仍需本人审定身份信息和 T22 §12 人工证据；最终提交候选不等于已提交或教师验收。

## 按用途查找

- **需求阶段**：`01` 要求清单 → `02` 流程与分工 → `03` 需求基线。
- **设计与实现**：`04_设计与控制文件/` → `backend/`、`frontend/`。
- **过程记录**：`07_AI使用留痕/` 保存决策、提示词和人工修改记录。
- **验证与审查**：`10_验收证据/` 按阶段保留原始结果、审查意见和处理记录；历史记录用于追溯，不自动代表当前状态。
- **课程提交**：`06` 测试报告、`08` 个人分析报告、`09` 运行与提交说明及 `11_最终提交候选/`。Markdown 是源稿，按课程通知在最终提交包中生成所需 Word。

## 新增与整理规则

先查本页和相邻目录，优先更新当前文档，不复制第二份同主题说明。新增课程文档归入 `docs/` 并沿用编号；代码归入对应源码目录；阶段证据归入 `docs/10_验收证据/`。修改或移动文件时同步更新 Markdown 链接，并保留冻结快照和原始证据的历史含义。
