# 前端最终验收与合并记录

> 2026-10-24。对象为 T22 前端工作台及其交付证据；此处的“完成”仅指前端开发批次收口，不代表整套系统的正式性能、安全或课程总验收通过。界面操作证据来自前端开发者留存的真实 HTTP/浏览器记录；本次复核没有重新操作浏览器。

## 验收流程与判定

1. **锁定版本**：记录每个 PR 的最终 head、合并提交及必需 `regression` 检查，避免用旧截图或旧审查结论替代最新提交。
2. **核对业务闭环**：按前台、医生、管理三类账号，逐项对照接诊及更正、病历及告警、人机分工与导出；核查真实服务、隔离服务和合成 VM 测试的证据来源，不把其中一种写成另一种。
3. **核对失败与权限边界**：检查 409 保留输入、403 无权目标、422 `GUARD_BLOCKED`、导出完整性校验及角色可见范围；没有独立浏览器证据的场景保留为“代码路径或自动测试覆盖”。
4. **核对界面证据**：检查最终截图数量、视口及缩放口径。接受的 Edge 2× device scale / 683 CSS 视口属于 200% 等效证据，浏览器菜单 200% 未验证。
5. **复审合并**：对最新 head 看差异、运行针对性检查、核对 CI；有阻塞问题则退回修复，没有阻塞问题则留下实际 COMMENT 审查记录并按保护规则合并。相同账号不能伪造独立批准。
